Core Concept

A geometric multi-FX processor: a pentagon control surface with 5 nodes, each representing an FX chain.

UI
Center: pentagon control surface with draggable mix control toward nodes
5 vertices = FX nodes
Node proximity = mix amount visualization (cursor shifts toward active nodes)
Each node has selectable FX type menu
Bottom panel: LFO manager (create/edit LFOs)
Side panel:
Grain size control (for granular FX)
Dry/Wet slider
Randomize button
Modulation
LFOs can modulate node mix amounts and parameters
Assign multiple LFOs per node
Smooth interpolation for all parameter changes
DSP
Each node runs an independent FX chain (pluggable architecture)
Support at least: delay, reverb, filter, granular processor (extensible)
Global mix + per-node mix control
Real-time safe, no allocations in audio thread
Architecture
Clean separation:
DSP engine (processing graph)
UI layer (control surface + panels)
Parameter system (APVTS recommended)
Fully extensible node/Fx system
Requirements
Low latency real-time audio safe
Smooth parameter automation
State save/restore
Prepare for future expansion (more nodes, FX types, modulators)
